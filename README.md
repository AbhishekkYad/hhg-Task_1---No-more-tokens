## 🌟 Overview

The **Hacker House Goa 2026 Graphic Generator** is a high-performance, client-side web tool designed for builders, engineers, designers, and founders. It allows anyone to upload a photo and instantly generate an official branded graphic to share on **X (Twitter)** with zero login wall or registration gates.

## ⚡ Key Features

* **Instant Client-Side Processing**: 100% browser-based rendering using HTML5 Canvas API—zero server delay, full privacy.
* **Interactive Canvas Drag & Pan**: Drag photos directly over the canvas preview using mouse or touch gestures.
* **Floating Auto-Center DP Button**: 1-click floating action button right on the canvas preview to automatically re-center the photo.
* **iPhone HEIC/HEIF Support**: Automatic client-side conversion for native Apple HEIC photos via `heic2any`.
* **High-Res PNG Export**: One-click download (`hh-goa-2026-pfp.png` or `hh-goa-2026-pass-name.png`).
* **Share on X Intent**: 1-click button to open a pre-filled tweet window with text, @HackerHouseGoa mention, and `#FrameInGoa #HackerHouseGoa` hashtags.

## 🚀 Local Setup & Installation

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/AbhishekkYad/hhg-Task_1---No-more-tokens.git
   cd hh-goa-2026-badge
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local dev server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

1. Go to your repo **Settings** → **Pages**.
2. Select **Branch: main** and `/root` folder.
3. Click **Save**.
